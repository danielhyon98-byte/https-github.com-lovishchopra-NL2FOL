# Missing files from the Epinoic AI context pack

The context pack README and `00_PROJECT_CONTEXT_AND_ARCHITECTURE.md` reference the
following files. As of the repository audit they have NOT been provided to this
repository or to the engineering session, so nothing in this repository is derived
from them:

- `specifications/02_Z3_Logic_Verification_Engine_Specification.md` (the governing
  Z3 logic translator and verification specification; originally titled as a Codex
  specification but model-independent)
- `specifications/03_Overseer_Agent_Specification.md`
- `references/ib-agent-training-pack-v2/` and `references/IB_Agent_Training_Pack_v2.zip`

`04_Claude_Code_Implementation_Kickoff.md` in this directory is the uploaded
"Claude Fable 5.1 / Claude Code Implementation Kickoff Prompt"; it is assumed to be
the same document the pack lists under that name.

The provisional implementation plan must be reconciled against the two missing
specifications before any phase is approved for implementation.
